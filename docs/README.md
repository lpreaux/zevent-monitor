# Documentation

| Dossier | Contenu |
| --- | --- |
| [plans/](plans/README.md) | plans de produit et d'architecture, décisions durables |
| [sources/](sources/README.md) | capacités mesurées des sources externes, formats d'import |
| [ops/](ops/postgres-backup-restore.md) | procédures d'exploitation du serveur et de la base |

Les plans décrivent ce que l'on veut faire, `sources/` ce que les sources permettent réellement de
faire, et `ops/` comment exploiter ce qui tourne. Un plan qui suppose une capacité de source doit
pouvoir pointer vers sa mesure dans `sources/`.
